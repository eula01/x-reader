# x-reader

Chrome extension that limits X to four list timelines and direct tweet links.

## Install

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. **Load unpacked** → select the `chrome-extension` folder
4. Reload the extension after pulling updates

See [`chrome-extension/README.md`](chrome-extension/README.md) for details.

## Allowed on X

- The four list URLs above, including subpages like `/members`
- Direct tweet links, e.g. `https://x.com/user/status/1234567890`

Everything else on x.com shows a full-page overlay with four buttons to your lists.
